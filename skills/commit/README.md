Inspired by https://github.com/JuliusBrussee/caveman/blob/main/skills/caveman-commit/README.md


# Expected

- Consistency: Commit message always keep same as the `git log` as first choice and ONLY followed by `Augular Conventional Commits` when there is no git log.
- Simpler: Keep it simple.
- Mutate: Commit all changes if there is no file in stage or commit stage files.
